# Vignettes

<!-- cg:auto:examples -->
### Examples

- Convert a local questionnaire to a typed SVIS JSON artifact.
- Run batch conversion over a set of questionnaires.
- Build a source-grounded routing multigraph. The graph uses native XLSForm relevance and repeat routing.
- Check the active configuration and discover installed providers with the `survey-scribe` CLI.
