# Security Policy

## Supported Versions

Survey Scribe is in alpha. Security fixes are applied to the latest revision on
the `main` branch until the first public release policy is approved.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private
vulnerability reporting for the repository and include:

- The affected version or commit.
- Reproduction steps or a minimal proof of concept.
- The potential impact and affected data.
- Any suggested mitigation.

Do not include credentials, restricted questionnaires, personal data, or raw
provider responses. The maintainers will acknowledge the report through the
private GitHub thread and coordinate remediation there.
